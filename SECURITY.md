# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/jsundquist/jsundquist.github.io/security/advisories/new).
Don't open a public issue or pull request for a security problem.

## Supported versions

Only the latest commit on `main` is supported. The site and its container image are rebuilt from
`main`, so fixes ship there.

## Response time

This is a personal project. Expect an acknowledgement within 7 days and a fix or status update
within 30 days.
